## Extended application description

Meet Starry: the command center for thriving Discord communities. Protect your server with moderation, verification and configurable safety tools. Keep members engaged with tickets, giveaways, leveling, events and community utilities. Manage supported modules from one connected dashboard, with server-scoped settings and clear permission checks. Starry brings your community tools together—so your staff can spend less time managing and more time building.

## Profile design direction

- Lead with the outcome: safer, better-managed communities.
- Group capabilities into readable categories rather than a long comma-separated feature list.
- Use a consistent 🌟 / indigo visual identity across the bot, dashboard, support server and documentation.
- Avoid unsupported claims such as “unbreakable security”, “100% protection”, “zero downtime” or “all-in-one streaming”.
- Mention only modules that are enabled and verified in the currently deployed build.

## Where to publish

1. Open Discord Developer Portal → Applications → Starry → General Information.
2. Replace the application Description with the extended description above (trim it if Discord's current limit requires it).
3. Open the Bot page and update the bot profile/About Me field with the short bio (trim to the current field limit if needed).
4. Save, then inspect the bot profile in Discord mobile and desktop.

Discord hosts this profile metadata. A repository commit alone cannot publish it; it must be saved in the Developer Portal by an application owner.
