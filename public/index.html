Quick answers about adding and managing Starry.

Starry is an all-in-one Discord management ecosystem combining server security, moderation, automation, support and community features with a web dashboard.

Use the Add to Discord button and complete Discord's authorization flow. You need permission to add apps to the server.

Select Dashboard Login or Continue with Discord. Starry uses Discord OAuth to identify your account and available servers.

Server configuration is managed through the dashboard. Available controls depend on the modules currently implemented and the permissions Starry has in that server.

Visit the project's GitHub Issues page to report a problem or request help. Include a clear description and relevant error details, but never post bot tokens or private credentials.
